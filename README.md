# Mini Hospital Emergency Management System

## Description

A Java-based Mini Hospital Emergency Management System developed using
different data structures to manage patients, emergency treatment requests,
treatment records, and patient visit history.

## Data Structures Used

- Binary Search Tree (BST) - Patient management
- Queue - Emergency treatment requests
- Stack - Treatment records
- Singly Linked List - Patient visit history

## Main Features

- Register patients
- Search patients
- Delete patients
- Display patients in ascending Patient ID order
- Add emergency treatment requests
- Process emergency requests using FIFO
- Manage treatment records using LIFO
- Maintain patient visit history
- Search and remove visit records
